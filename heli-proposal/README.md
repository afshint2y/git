# Heli Studio Proposal — Pocky

Project proposal (Visual Identity & Packaging Design) for Pocky Group AB, reference HS-2026-042, as a standalone static page.

- `index.html` — the full proposal: styles, content (`PROPOSAL` config object) and interactions in one file.
- `assets/` — cover film, poster and imagery used by the page; `assets/work/` holds the case study images (Heli Technology, Money Mend, Dizno).

Open `index.html` in a browser, or serve the folder:

```sh
cd heli-proposal && python3 -m http.server 8000
```
